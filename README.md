# E-Commerce PPL

## Deskripsi Proyek
Proyek tugas akhir mata kuliah Proyek Perangkat Lunak (PPL)
berupa aplikasi e-commerce untuk UMKM yang menjual produk
atau barang. Pengembangan menggunakan pendekatan Agile
dengan Scrum sederhana.

## Rencana Fitur
- Pengelolaan produk oleh admin.
- Katalog produk untuk pembeli.
- Keranjang belanja dan checkout.
- Integrasi API pembayaran dalam mode sandbox.
- Integrasi API pengiriman untuk menghitung ongkos kirim.
- Daftar pesanan dan status pesanan.
- Minimal satu komponen komputasional untuk membantu
  pengambilan keputusan UMKM.

## Tools Proyek
- Manajemen tugas: Jira
- Komunikasi tim: Discord
- Repositori kode: GitHub

## Teknologi Aplikasi
Teknologi frontend, backend, database, serta layanan
pembayaran dan pengiriman akan dilengkapi sesuai keputusan
kelompok.

## Anggota dan Peran
Lengkapi dengan nama anggota, peran, dan username GitHub
masing-masing.

## Cara Menjalankan Aplikasi
Petunjuk menjalankan aplikasi akan dilengkapi setelah
implementasi awal tersedia.
